# Faishak Sales Quest

Node 24: `npm ci --ignore-scripts`, `npm start`. The server uses port 3000 or PORT. Run `npm run check`, `npm test` and `npm run build`.

The approved Home design is retained with generated image assets and SVG icons. `index.html` contains markup; `styles.css` styling; `app.js` original functionality; `knowledge.js` application guidance; `workspace.js` connected sales workflows.

## Working locally

- Plan completion is completed required objectives divided by all 12 required objectives. Elapsed days are separate, calculated from your selected start date. No fixed 42%.
- KPIs use saved opportunity, dated completed meetings for the current Singapore week, and qualification records. Date undated legacy meetings in the metric editor. Existing records are retained; fresh local browsers contain clearly labelled demo opportunities.
- BCI recipes require package keywords and do not query BCI directly.
- Academy explains brands, origins, applications, buyer roles, selection considerations and evidence. Exact catalogue confirmation remains pending.
- Competitor templates distinguish research candidates, supported strengths and evidence gaps.
- Outreach includes five branching cadences, timing, messages and stop conditions.
- Pipeline includes company/contact, editable dated update history, next-action due dates and a record-based meeting script.
- Project Brief captures relevant scope, timing, stakeholders and next action before a pipeline entry.
- Home shows coaching focus, overdue actions and an RSS news carousel.
